2. FIG. 2: DECISION FLOWCHART & CRITICAL THREAT OVERRIDE SHIELD
================================================================================

```mermaid
flowchart TD
    %% ========================================================================
    %% FIG. 2: Decision Flowchart of Multi-Vector Risk Calculation & Override
    %% ========================================================================

    START(["200 Start Manifest Audit Run"])
    INGEST["202 Ingest Dependency Manifest File & Normalize Coordinates (p, v, e)"]
    
    START --> INGEST

    PARALLEL["204, 206, 208 Execute Multi-Vector Feature Extraction in Parallel:<br/>• 204: Compute Levenshtein & Jaro-Winkler Distances (S_typo)<br/>• 206: Query Cache/OSV & Calculate Compound CVSS Score (S_vuln)<br/>• 208: Inspect Registry Metadata & Version Pinning (S_maint)"]
    
    INGEST --> PARALLEL

    RAW["210 Calculate Raw Baseline Weighted Risk Score:<br/>S_raw = 0.45 * S_vuln + 0.35 * S_typo + 0.20 * S_maint"]
    
    PARALLEL --> RAW

    PEAK["212 Determine Peak Acute Threat Signal:<br/>M = max(S_vuln, S_typo)"]
    
    RAW --> PEAK

    D1{"214 Is Peak Threat M >= 9.0?<br/>(Critical Remote Code Execution or Blatant Typosquat)"}
    
    PEAK --> D1

    CRIT["216 Apply Critical Threat Override Shield:<br/>S_final = max(S_raw, M * 0.95)<br/>(Guarantees Escalation to CRITICAL Tier [9.0 - 10.0])"]
    
    D1 -- YES --> CRIT

    D2{"218 Is 7.5 <= M < 9.0?<br/>(High-Severity CVE or Close Typo)"}
    
    D1 -- NO --> D2

    HIGH["220 Apply High-Threat Override Shield:<br/>S_final = max(S_raw, M * 0.90)<br/>(Guarantees Escalation to HIGH Tier [7.5 - 8.9])"]
    
    D2 -- YES --> HIGH

    BASELINE["222 Retain Baseline Weighted Score:<br/>S_final = S_raw<br/>(No Acute Threat; Standard Multi-Attribute Weighting)"]
    
    D2 -- NO --> BASELINE

    TIER["224 Bin Final Score S_final into Standard Categorical Risk Tier:<br/>• SAFE (0.0 to 2.9)<br/>• LOW (3.0 to 5.4)<br/>• MEDIUM (5.5 to 7.4)<br/>• HIGH (7.5 to 8.9)<br/>• CRITICAL (9.0 to 10.0)"]

    CRIT --> TIER
    HIGH --> TIER
    BASELINE --> TIER

    GATE{"226 Evaluate Final Risk Tier Against CI/CD Policy Gate<br/>(e.g., --fail-on HIGH)"}

    TIER --> GATE

    EXIT0["Policy Check Passed:<br/>Emit UNIX Process Exit Code 0<br/>(Allow CI/CD Pipeline to Proceed)"]
    EXIT1["Policy Check Breached:<br/>Emit UNIX Process Exit Code 1<br/>(Halt CI/CD Pipeline & Block Deployment)"]

    GATE -- S_final < Policy Threshold --> EXIT0
    GATE -- S_final >= Policy Threshold --> EXIT1

    EMIT(["228 Emit Machine-Readable JSON Findings & Color-Coded Terminal Tables"])

    EXIT0 --> EMIT
    EXIT1 --> EMIT
```

FIG. 2 REFERENCE NUMERALS (200 SERIES):
  - 200: Start manifest audit run
  - 202: Ingest manifest and normalize dependency coordinates (p, v, e)
  - 204: Compute typosquatting edit distances and separator confusion (S_typo)
  - 206: Query cache/OSV and calculate compound CVSS score (S_vuln)
  - 208: Inspect maintainer metadata and version pinning status (S_maint)
  - 210: Calculate raw baseline weighted risk score (S_raw)
  - 212: Determine peak acute threat signal M = max(S_vuln, S_typo)
  - 214: Decision block: Is M >= 9.0?
  - 216: Operational step: Apply critical override S_final = max(S_raw, M * 0.95)
  - 218: Decision block: Is 7.5 <= M < 9.0?
  - 220: Operational step: Apply high-threat override S_final = max(S_raw, M * 0.90)
  - 222: Operational step: Retain baseline weighted score S_final = S_raw
  - 224: Bin final score into categorical risk tier (SAFE, LOW, MEDIUM, HIGH, CRITICAL)
  - 226: Evaluate against CI/CD policy gate threshold and emit exit code 0 or 1
  - 228: Emit machine-readable JSON findings and color-coded terminal tables

FIG. 3 REFERENCE NUMERALS (300 SERIES):
  - 300: Embedded SQLite caching subsystem architecture
  - 302a: CI/CD build runner process 1
  - 302b: CI/CD build runner process 2
  - 302c: Local developer CLI execution process
  - 304: Namespace-scoped key construction module
  - 306: Write-Ahead Logging (WAL) shared memory ring buffer
  - 308: Primary SQLite database file (scds_cache.db)
  - 310: Concurrent non-blocking read and write transactions
  - 312: External REST APIs (OSV.dev, PyPI, npm)
  - 314: Lazy TTL expiration and cache eviction module
