# ==============================================================================
# Supply Chain Dependency Risk Scorer (SCDS) - Novice Test Suite
# File: novice_test_suite.txt
# Ecosystem: PyPI (Python Package Index)
#
# PURPOSE FOR NOVICES & STUDENTS:
# This test suite is designed as a beginner-friendly benchmark for testing
# software supply chain vulnerability detection. It provides clearly labeled,
# realistic dependency examples covering all 5 supply chain risk tiers:
#
#   1. SAFE        (Score: 0.0 - 2.9)  -> Verified legitimate, cleanly pinned
#   2. LOW RISK    (Score: 3.0 - 5.4)  -> Version hygiene & unpinned warnings
#   3. MEDIUM RISK (Score: 5.5 - 7.4)  -> Transposition typosquatting attempts
#   4. HIGH RISK   (Score: 7.5 - 8.9)  -> Known CVE vulnerabilities (CVSS 7.0+)
#   5. CRITICAL    (Score: 9.0 - 10.0) -> High-confidence typosquats & RCE CVEs
#
# HOW TO RUN THIS TEST SUITE:
# ------------------------------------------------------------------------------
# 1. Standard scan (generates human-readable terminal table):
#      python3 -m scds scan novice_test_suite.txt
#
# 2. CI/CD Pipeline Gate (fails build if HIGH or CRITICAL risks exist):
#      python3 -m scds scan novice_test_suite.txt --fail-on HIGH
#
# 3. Export Machine-Readable JSON (for automated scripts or web hooks):
#      python3 -m scds scan novice_test_suite.txt --json
#
# 4. View in Interactive Web Dashboard:
#      Upload this file at http://localhost:8765
# ==============================================================================
